# Contributing to Gareji MCP

Gareji MCP is currently a private design scaffold. These rules prepare the contribution surface without authorizing publication.

Before implementation, read [CONTEXT.md](CONTEXT.md), [the architecture](docs/architecture.md), and [the v0 tool contract](docs/tool-contract-v0.md). Keep this repository a transport Adapter: behavior that must be identical for Runner, CLI, Hook, and MCP belongs in Gareji Core.

Use one coherent meaning per commit and an English Conventional Commit subject, such as `feat(checkpoint): expose durable progress receipts`. Record exact conformance and permission checks in the message body.
