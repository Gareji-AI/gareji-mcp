# Security policy

Gareji MCP may expose local project context and accept progress records. Enable it only for intended clients and grant permissions per project.

Do not open a public issue containing credentials, personal paths, private notes, customer data, raw transcripts, full diffs, or Core Audit sidecars. Use GitHub private vulnerability reporting when enabled, or an already established private maintainer channel.

The v0 MCP Interface intentionally excludes arbitrary shell, generic file writes, Git mutation, publication, and secret access. A request for one of those capabilities is a product and threat-model change, not a small tool addition.
